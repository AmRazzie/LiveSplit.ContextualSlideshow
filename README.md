# LiveSplit.ContextualSlideshow
Contextual Slideshow is a LiveSplit component that cycles between few different information components in a single row.  
I found this component unfinished and without a settings panel, I added those using Copilot and built a working version.  
![gif](https://i.imgur.com/xsQJcWl.gif)

# Build requirements  
• Visual Studio  
• .NET Framework 4.8.1 Developer Pack
